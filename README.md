# Coast 2030 · 个人长期计划总纲

> 核心原则：不押未来奇迹，只追踪当下可兑现的现金流与可复用能力。

## 终极目标（2030）

- 状态：可自由退休，不依赖单一平台或单一产品
- 资产：现金结余 > `500 万`（理想 `2000 万`）
- 系统：拥有可持续运转的个人事业系统

### 重要口径变化（相对旧计划）

1. **2026 自然年 ¥1,000,000 已正式脱靶**：截至 2026-10-01 实际到账 ¥360。缺口留待年末复盘，作为 2027 目标校准输入；Q4 只认 100 天战役的 ¥500k 单一数字。
2. **收入线收敛为一条**：SaaS 是唯一收入线；自媒体（YouTube）只做获客引擎，不设独立收入目标。
3. **AIBounty / Hunter 已停摆**（2026-09-19 起）：不投入新工时，仓库只读维护；被动到账算额外收入，见 [`../AIBounty/README.md`](../AIBounty/README.md)。
4. **旧的逐月爬坡目标（¥30k→¥110k）作废**：连续 4 个月零达成，已失去指导意义。
5. **产品数据唯一事实源是线上看板**（productlab.pxiaoer.blog）；本地不再维护产品档案。

## 每日时间预算（8H）

- **5H SaaS**：2H 付费路径与转化 · 2H 产品交付 · 1H 数据与复盘
- **2H YouTube/内容**：每周 ≥1 条，只服务 SaaS 获客，全 UTM 归因
- **1H 机动**：只补最接近付款的阻塞项

## 执行策略

| 维度 | 原则 |
| :--- | :--- |
| 收入 | 只认实际到账；Expected / 意向 / 报价一律不计进度 |
| 产品 | 同时只有 1 个主产品（当前 **openbot.ai**）+ 至多 1 个 standby；连续 3 个月无真实付款直接止损 |
| 记录 | 收入、任务、进度全在 Dashboard；文档只定策略与边界，不复制易过期数字 |
| 复盘 | 四个季度 Gate 只做三件事：对账、砍项、重排 |

## 铁律

1. SaaS 上线后若连续 3 个月未达到关键付费指标，直接止损
2. 同时在研项目不超过 2 个
3. 现金为王：只相信已到账收入
4. 复盘优先于扩张：先闭环，再加速
