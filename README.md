# Coast 2030 · 个人长期计划总纲

> 核心原则：不押未来奇迹，只追踪当下可兑现的现金流与可复用能力。

## 终极目标（2030）

- 状态：可自由退休，不依赖单一平台或单一产品
- 资产：现金结余 > `500 万`（理想 `2000 万`）
- 系统：拥有可持续运转的个人事业系统

## 2026 收入与时间分配

2026 年总收入目标保持 **100 万元实际到账**，只调整三条业务线的责任比例：

| 方向 | 年度收入目标 | 每日时间预算 |
| :--- | ---: | ---: |
| SaaS | ¥600,000（60%） | 5H |
| 自媒体 | ¥250,000（25%） | 2H |
| AIBounty / Hunter | ¥150,000（15%） | 1H |
| **合计** | **¥1,000,000** | **8H** |

AIBounty 的 1H 是日均预算，可以合并为连续深挖块；同一笔收入只能归属一条业务线。软件订阅/API/License 归 SaaS，广告/商单/赞助/Newsletter 订阅归自媒体，漏洞平台实际到账奖金归 Hunter。

## 执行策略

| 维度 | Hunter（机会副线） | Farmer（收入主线） |
| :--- | :--- | :--- |
| 方向 | 漏洞挖掘 / 热点工具 | SaaS 主线 / 个人 IP |
| 关键词 | 快速验证、高回报、高止损 | 复利、留存、护城河 |
| 目标 | 用 1H/天预算保留高回报机会 | SaaS 5H/天 + 自媒体 2H/天，构建稳定底座与长期增长 |
